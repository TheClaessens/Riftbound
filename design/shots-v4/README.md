# v4 shots (heroes + spell VFX)

Saved frames from verifying the v4 overhaul.

- `base-*`: the v3 baseline (before).
- Everything else: v4 (after).
  - `*-hero-*`, `pyro-*`, `cryo-*`, `arc-*`: hero models.
  - `fire-*`, `frost-*`, `storm-*`, `arcane-*`, `mix-*`: abilities, reactions and statuses.
  - `int-*`: each hero casting in game.

Make new frames with `src/dev/shot.js` (shots server, port 8097) → `dev/shots/`.
