# Riftbound UI v3 — "Crownforge" spec + implementer contract

Locked from `design/UI_PASSES.md`. Research: `design/research/05-ui-art-direction.md` (art), `06-ui-tech.md` (CSS/SVG tech, drop-in code), `07-hud-information-design.md` (layout, hierarchy, accessibility). When this doc and a research doc disagree, **this doc wins**.

## 1. Direction in five lines
1. **The UI is the reliquary of the shattered Riftcrown.** Plates are cool violet-black **rift-iron**, cut with **chamfers** (never rounded), flat two-tone facets lit from the upper-left, a **crown-bronze** bezel and a 1 px void keyline.
2. **The four Primes appear only as gems/enamel/icon bodies** (fire `--fire`, frost, storm, arcane). Chrome itself is achromatic-cool + bronze. Each element also has a **shape** (fire = flame-cut gem, frost = hexagon, storm = bolt-cut diamond, arcane = 4-point star: icons `el-*`).
3. **The prism crack** (`.cf-prism`, `--prism`) is reserved for crown moments: fusions, Aurelith/Prism Ward, Rift Shift, victory.
4. **Three frame tiers:** Tier 1 `.cf-frame` (ornate: skill bar, boss bar, modals) · Tier 2 `.cf-plate` (tray, tooltips, toasts) · Tier 3 frameless outlined text (timer, Chain, labels). **Most of the HUD is Tier 3.** Ornament is earned and must encode something.
5. **Never:** emoji/unicode glyph icons (use `icon()`), pills, `border-radius` on frames (only true circles: gems, orbs, pips), gradients without a light source, glows on chrome, Cinzel/Inter, magenta (`--threat-shot`) or telegraph red-orange as decoration, translucent glass panels over the world, `backdrop-filter`.

## 3. Scale and units
- `src/ui/scale.js` sets the root font size: **1rem = 12 / 15 / 20 px at 1280×720 / 1920×1080 / 2560×1440**, snapped to device pixels.
- **Author every size in 1080p pixels with `--u`:** `width: calc(64 * var(--u))`. At 720p that is 51 px. Wrap pixel-critical boxes in `round(…, 1px)` (or `2px` for things centred on a half).
- Text floors at 720p (automatically satisfied if you use these sizes at 1080p): key caps/badges 14u (≤3 chars only), labels 15–16u, body/effect 18–20u, important numbers 20–32u, names 26–28u, hero ≥ 48u.
- Never `transform: scale()` a resting UI. Pops end at `transform: none`.

## 4. Tokens and primitives (css/theme.css)
Use these; don't redefine them. You may add screen-specific variants in your own CSS file (prefix your classes: `hud-`, `md-`, `mn-`).

- **Colours:** `--cf-void --cf-plate-0..3 --cf-enamel(-hi) --cf-bronze-lo/--cf-bronze/--cf-bronze-hi --cf-gilt --cf-text --cf-dim --cf-faint`, Primes `--fire/-lo/-hi` (same for frost, storm, arcane, phys), `--rift-white --prism --act-thornwood/-barrens/-reach --hp/-hi/-lo/-chip --shield --xp --risk`. Grads: `--metal-grad --gilt-grad --iron-grad --iron-grad-hi`.
- **Element binding:** `data-el="fire|frost|storm|arcane|physical"` sets `--el --el-lo --el-hi` for everything inside (icons, sockets, `.cf-hl`).
- **Fonts:** `--font-hero` Grenze Gotisch (≥ 32u only, never numbers) · `--font-head` Grenze 700/800 (names, titles, buttons) · `--font-label` Alegreya Sans SC 700/800 (labels; write text in lowercase, the SC face makes small caps) · `--font-body` Alegreya Sans 500/700/800 (body + **all numbers**, use `.num` = tabular lining figures).
- **Classes:** `.cf-plate` (+`.flat`, `.sunken`) · `.cf-frame` (+`.crown` = crown point on top edge) · `.cf-socket` (+`.round` auto skill, `.empty`, `.lit`; `--sz`) · `.cf-bar` (+`.capped`; children `.cf-bar-track > i.cf-bar-ghost / i.cf-bar-fill / i.cf-bar-shield / i.cf-bar-ticks`, `.cf-bar-num`; `--h --fill --n`) · `.cf-btn` (+`.primary`, `.danger`) · `.cf-key` · `.cf-pips > i(.on|.new)` (`--pip`) · `.cf-label .cf-h .cf-hero .cf-body .cf-dim .cf-hl` · `.cf-rule > i` · `.cf-prism` · `.cf-tip` · `.cf-backdrop` · `.num` · `.outlined` (4 px void stroke for text over the world).
- **Ornament masks** (geometry only; colour = your `background`): `--orn-tl/-tr/-bl/-br` (corner bracket), `--orn-crown` / `--orn-crown-d` (crown point up/down), `--orn-cap-l/-r` (bar finials). Pattern: a pseudo-element with `mask: var(--orn-crown) center / W H no-repeat; background: var(--gilt-grad)`.
- **Motion:** `--ease-forge` (settle), `--ease-stamp` (overshoot: seals, pips, pops), `--ease-rift` (exits, rift pulls). One hero motion per moment; modal intros ≤ 450 ms; honour `prefers-reduced-motion`.
- Live reference: **`/dev/ui-kit.html`** renders every primitive over the three ground colours.

## 5. Icons
- Sprite: `src/ui/icons/index.js` (`ensureIcons()` runs at boot in main.js). Markup: `icon(id, { el, cls, title, fallback })` → `<svg class="ico" data-el=…><use href="#i-id"/></svg>`. `.ico` is `1em` square: size it with `font-size` or width/height. Missing ids render the `fallback` glyph, so pass the old `def.icon` as fallback.
- Id helpers: `ICON.skill(id)`, `ICON.relic(id)`, `ICON.passive(id)`, `ICON.attune(id)`, `ICON.cls(id)`, `ICON.el(el)`, `ICON.dash(kind)`, `ICON.buff(id)`, `ICON.react(id)`, `ICON.ui(name)`, `cardIconId(card)`.
- **Ids that must exist** (icon agents own these lists):
  - Skills (`skill-`): arcaneBolt cinderBolt iceShard spark fireball frostNova chainLightning meteor blizzard singularity spiritOrbs staticField · Fusions (`skill-`): frostfireComet plasmaOrb stormHalo arcaneBarrage absoluteZero cataclysm thunderhead starfall hailstorm tempest · Dashes: dash-blink dash-flame dash-frost dash-storm
  - Relics (`relic-`): alchemistsCoil prismLens unstableCore emberHeart pyreCrown rimeShard glacierPlate stormglassBoots conductorsRing glassSigil bloodPact duelistsMark thornedWard hoardersLantern riftMagnet echoStone overclock secondWind · Reactions (`react-`): steam overload superconduct shatter combust arcflash
  - Passives (`passive-`): might haste swiftness vitality magnetism amplify catalyst precision volley · Attunements (`attune-`): might vigor insight swiftcast fortune exile · Classes (`class-`): arcanist pyromancer cryomancer stormcaller · Buffs (`buff-`): adrenaline fury celerity greed aegis · Elements (`el-`): fire frost storm arcane (**done**) · UI (`ui-`): shard essence reroll banish lock chest surge swarm boss shrine auto tome gear mouse-l mouse-r tier clock help
- **Style contract:** 48×48 viewBox, 40-unit live area (fill 60–75% of it; chunky, readable at 24 px). Filled silhouettes (never line icons), **3 flat tones + a 2-unit ink outline drawn under the fill** (`style="stroke:var(--ink);stroke-width:2;stroke-linejoin:round;paint-order:stroke"`), lit from the upper-left as flat facets. No gradients, no filters, no text, no perspective (except a ground ellipse for ground-targeted spells). Colours only through `style="fill:var(--…)"` (never `fill="var(…)"` attributes):
  - skills/fusions/dashes = energy in `--el-lo/--el/--el-hi`, projectiles fly lower-left → upper-right, novas radial, ground spells over an ellipse; fusions = parent A's silhouette with parent B's cut in.
  - relics = physical objects in `--metal-lo/--metal/--metal-hi` (+ `--glass`) with **one accent** in `--acc` (set by the UI from the relic tag) or a fixed Prime var where the relic is element-bound.
  - passives/attunements = engraved sigils on a round bronze token. Classes = a crown point with the class Prime gem. Reactions = the two element gem shapes colliding (fixed Prime vars). UI glyphs = simple, bold, 1–2 tones + ink.
  - Internal `<defs>` ids must be prefixed `i-<iconid>-…`.
- Gallery: **`/dev/icons.html?filter=relic-&cell=320`** shows each icon at 24/32/48/96 px on plate, grass, barrens, water (`&el=fire` forces an element).

## 6. HUD (owner: HUD agent)
Zones (1080p boxes, see research 07 §11 for the full table; adapt to Crownforge):
- **Top centre — act timeline** (Tier 3 over a slim plate): 3 act gems (done = gilt, current = act colour, upcoming = hollow), a 0:00–3:00 timeline with beat markers at `BEATS` (`import { BEATS } from '../game/spawner.js'`: Elite Surge 90 s `ui-surge`, Swarm 135 s `ui-swarm`) and the boss at `ACT_LENGTH` (`ui-boss`), timer in 28–32u tabular numerals. A **beat ribbon** under it shows "Elite Surge in 0:08" for the last 10 s before a beat and the beat name for 3 s after. **Delete** "ACT I · NAME" text and the "Lv · kills" line. Primer clock hold (`game.tutorial.holdClock`) shows a paused state.
- **Top centre — boss bar** (Tier 1 `.cf-frame.crown`, ~880×20u bar): boss name (split `bossName` at the comma: "Gorrak" in Grenze 28u, epithet in labels 16u), hp fill + JS-driven ghost chip, **phase notch at 50%** (crown point marker; `boss.phase`), **ward badge** at the left end when `boss.ward` is set: element gem icon + countdown ring from `boss.wardT / WARD_CYCLE` (`import { WARD_CYCLE } from '../game/bosses.js'`); the prism crack runs along Aurelith's bar. While a boss lives, the act timeline collapses to a slim strip. **Boss intro:** on `bossSpawned` the name plate stamps in large at centre (≤ 1.2 s) then settles into the bar.
- **Bottom centre — action bar** (Tier 1, one plate, ≤ 92 px tall at 720p total incl. HP): dash socket (`.hud-dash`, charges as pips inside the bottom edge with recharge fill), 5 skill sockets (`.hud-slots`; LMB/RMB as `ui-mouse-l/-r` key glyphs, Q/E/R as `.cf-key`), round auto-skill sockets, an auto-cast toggle chip (`ui-auto`, lit when on). HP bar (`.hud-hp`, `.cf-bar.capped`, ticks every 25%, shield hatch, ghost chip, number = current HP only) above the slots, a 4u XP line, a level chip. Slot anatomy: icon 40u in socket; cooldown = dark conic sweep with a 0.7° feather + whole-second number only while cd ≥ 1 s; sub-second starters never sweep (dim only); **ready = one gilt glint**, never a loop; rank as pips; fusion slots get a prism-crack bezel accent. Buffs: 36u icon squares (`buff-*`) with a radial timer and seconds, above the HP bar, no names.
- **Under the character — status cluster:** projected from `player.pos` each frame (same math as the shrine marker), 72×7u HP bar with void outline + dash pips + Frost Armor pips (Permafrost) + Momentum strip (Stormcaller, hot > 80). 70% opacity, 100% on hit/low HP. **This replaces the trait panel and the duplicate armor row.**
- **Right lane — Chain & reactions:** Chain ×N fixed size 56–64u, colour ramp white → amber (`#e0a030`) → prism (≥ 25) — **no magenta**; milestone stamp beside it (no centre pill); Arcanist Resonance meter (25 ticks + "+N% dmg") under Chain; reaction feed rows = two element gems + name + ×n; **discovery toasts** (new reaction / fusion forged / relic) slide in from the right (`.cf-plate`, kicker + title + one line). `.hud-chain` class must remain (tutorial glow hook).
- **Top left — relic tray:** 36u relic icons on one plate, `pointer-events: none` during play, tag accent `--acc` from `RELIC_TAG_COLOR`.
- **Edge markers:** generalise the shrine marker to `{ shrine, relic bearer (enemy.dropsChest && !dead), chests (game.pickups.items type 'chest') }`: icon disk + distance, no text label, clamped to a safe rect that excludes the action bar and top bar.
- **Centre announcements:** `announce` events now carry `kind` (`surge`, `swarm`, `boss`, `bossDown`). Beats go to the ribbon; only `boss`/`bossDown` use a short centre stamp. Act title card (Grenze Gotisch numeral + name + act-colour hairline, ≤ 2.3 s), Rift Shift flash, PERFECT stamp (above the character, 0.4 s) stay in `hud-fx.js`.
- **Low HP:** opacity pulse of a pre-drawn layer ≤ 1 Hz on the HP bar + cluster. Tone down the current full-screen red vignette (it currently tints the whole screen red).
- **Perf:** per-frame updates only through `hud-util` setters; fills via `transform`, never `width`/`left`/`font-size`; no filters/box-shadow animations/`restartAnim` in hot paths (WAAPI for one-shots); `contain: layout style` on clusters.

## 7. Modals (owner: Modals agent)
- **Level-up** ("The Rift offers…", "Level N"): 3 cards ~340×420u, keys **1-3**, **F** reroll, **X** banish (Esc cancels banish mode). Card: key cap top-left, type sigil top-right (NEW / RANK UP / FUSION / PASSIVE / RESTORE), big element-shaped medallion (socket) with the icon (`cardIconId(card)`), name (Grenze 26u), rank pips **before → after** (new pip glows), **effect as a delta** (diff `def.desc(rank-1)` vs `def.desc(rank)` and render changed numbers as `old → new` in `.cf-hl`; new skills show the description), one synergy line from `card.hint`, footer (element gem + Active/Auto). Card shape by type: fusion = double-notched frame + prism crack, passive = round medallion, restore = plain. **Loadout strip** under the cards shows the current dash/slots/autos/passives; hovering a card highlights the slot it affects. Input lock 250–350 ms and ignore keys already held when it opened.
- **Relic chest** ("Bind a relic"): 3–4 plinth cards, object icon large, tag sigil + tag word, effect line, one context line; **no flavour on the card**. Keys 1–4.
- **Pause** ("Paused"): Resume (Enter/Esc) + Abandon (double-confirm). Tabs **Build / Codex**. Build = loadout with ranks (dash, slots, autos, passives) · **element square** diagram (4 gems on corners, the 6 reactions on sides + diagonals; discovered = lit name, else "???") · **fusions in reach** (owned parent ranks, "needs r3") · relics with flavour. Codex = reactions (element square), fusions as recipe tiles (icon + icon = icon), relics as an 18-tile icon grid (locked = enamel silhouette). Optional small settings row: shake, auto-cast.
- Shared: `.cf-backdrop` vignette, Tier 1 frame, entrance motion per research 05 §6 (cards deal up with stagger ≤ 60 ms, stamps on the title).

## 8. Menus (owner: Menus agent)
- **Title / Sanctum — make it a place:** the live world stays visible (only screen edges shaded). Wordmark "Riftbound" in Grenze Gotisch with a crown point and prism hairline; gate it on `document.fonts.load` (≤ 1.5 s) to avoid FOUT. **Class select = 4 medallions** (class sigil `class-*` in a socket, keys 1–4, lock state + unlock text) and **one details panel** for the selected class (name, title, starter skill icon + name, dash, trait, playstyle, tilt). **Rift Tier** = a dial/row of 6 gem steps with one modifier line. **Attunements** = 2×3 tiles (icon, rank pips, cost with `ui-shard`), description on hover/focus. **Begin Quest** = the biggest button (primary, Enter). Rift Shards counter top-right (`ui-shard`). Codex/record summary as a tome (`ui-tome`) chip. Settings (unlock all, auto-cast, tutorial, shake) behind a gear popover; controls behind a "?" popover. Keep every existing behaviour and meta call (`buyAttunement`, `saveMeta`, `isUnlocked`, keyboard 1–4/Enter).
- **End screens:** Fallen / Victory hero line (Grenze Gotisch), sub-line (class · tier), shard reward counting up, a ledger of stats (engraved rows), reactions as element-gem pairs with counts, fusions and relics as icons, unlock callouts, Quest Again (Enter) + Return to Sanctum. Victory gets the prism crack.

## 10. Verification (mandatory for every agent)
Dev server: `http://localhost:8080/index.html?unlockall` (already running; do not start servers). Use the built-in browser tools **only in your own tab**: create one tab once (`tabs_create`), always pass that `tabId`, never touch/close/navigate other tabs. The viewport is 1280×720 (rem = 12 px); screenshots come back at 800×450, so use `computer zoom` on regions to judge crispness.
- Harness: `const U = await import('/src/dev/uishots.js?v=' + Date.now());` then `await U.hud({ classId, act, boss, build: 'full'|'mid'|'none', relics, buffs, chain, hp, shield, shrine, dashUsed })`, `U.levelUp()`, `U.relicPick(4)`, `U.pause('build'|'codex')`, `U.title()`, `U.gameOver()`, `U.victory()`. The sim is frozen after each call; `U.step(seconds)` advances it, `U.render()` redraws.
- **Before every screenshot, reload your tab** (`navigate` to the same URL with a new `?v=`), because modules are cached.
- Check every class (4), every act (3), boss on/off (Aurelith for the ward), chain ≥ 25, low HP, empty build and full build, and `read_console_messages` for errors.
- Judge against the bar: does it look **authored and of this world** (iron, bronze, crown, Prime gems), is every number readable at a glance at 720p, is anything covering the play centre, does it stay crisp (no blurry text, no half-pixel hairlines)?
- When done: `U.restoreMeta()`.
- Final report < 40 lines: what you built, what you verified (with which states), open issues, any change you need in a file you don't own.
